# 店舗詳細ボタン設計
## 目的
検索結果の店舗カードから、アプリ内の店舗詳細画面へ移動できるようにする。

現在は店舗カード下部に「ホットペッパーで見る」と「地図で開く」を表示している。
「ホットペッパーで見る」は外部サイトへ移動する導線のため、その前に「詳細を見る」ボタンを追加し、まずアプリ内で店舗情報を確認できるようにする。

## 基本方針
店舗一覧で取得済みの `Shop` 型データをもとに、ポップアップ形式の詳細表示を行う。
「詳細を見る」を押したタイミングで店舗IDを使って Hot Pepper API へ再問い合わせし、詳細画面で表示できる情報を増やす。

理由:
- 一覧画面では比較しやすい最低限の情報に絞り、詳細画面では判断材料を多く出したいため
- 店舗IDで再取得することで、詳細画面用の項目を追加しやすくなるため
- 定休日、個室、禁煙、カード可、駐車場、クーポンURLなどを詳細画面に表示できるため

「詳細を見る」はアプリ内の画面状態を変更する操作なので、外部リンクではなく `button` 要素として実装する。
詳細情報は画面下へ移動するのではなく、モーダルとして現在の画面上に重ねて表示する。

再問い合わせに失敗した場合は、一覧で保持している `Shop` の情報だけでモーダルを表示する。
これにより、API通信に失敗しても最低限の詳細確認はできるようにする。

モーダルにする理由:
- 一覧画面の位置を保ったまま詳細を確認できるため
- 詳細を閉じるだけで、見ていた検索結果に戻れるため
- 「気になる店をいくつか比較する」操作と相性が良いため

## 対象画面
以下の店舗カードに「詳細を見る」ボタンを追加する。

| 画面 | 対象 |
| --- | --- |
| カテゴリ詳細画面 | ご当地カテゴリを選択した後に表示される店舗一覧 |
| 通常検索結果画面 | キーワードや条件で検索した後に表示される店舗一覧 |

カテゴリ一覧の小さい店舗候補は、カテゴリカード全体がカテゴリ詳細へ進む導線になっているため、今回の追加対象にはしない。

## 表示位置
店舗カード下部の `.shop-actions` に、以下の順番でボタンを表示する。

1. 詳細を見る
2. ホットペッパーで見る
3. 地図で開く

「詳細を見る」は「ホットペッパーで見る」の左側に置く。
外部サイトへ移動する前に、アプリ内で店舗の詳細を確認できる流れにする。

## 画面イメージ
店舗カード下部:

```text

```

「詳細を見る」を押した後:

## 状態管理
`src/App.tsx` に、詳細表示用の状態を追加する。

```ts
const [selectedShop, setSelectedShop] = useState<Shop | null>(null)
const [selectedShopDetail, setSelectedShopDetail] = useState<ShopDetail | null>(null)
const [shopDetailStatus, setShopDetailStatus] = useState<'idle' | 'loading' | 'ready' | 'error'>('idle')
```

| 状態 | 内容 |
| --- | --- |
| `selectedShop` | 一覧から選択した店舗。詳細取得に失敗した場合のフォールバックにも使う |
| `selectedShopDetail` | 詳細表示用に取得した店舗情報 |
| `shopDetailStatus` | 詳細情報の取得状態 |

`selectedShop` がある場合はモーダルを表示し、`null` の場合は表示しない。
モーダルを閉じるときは `setSelectedShop(null)` を実行する。
表示内容は `selectedShopDetail` を優先し、取得できていない場合は `selectedShop` を使う。

## 処理フロー
1. ユーザーが店舗カードの「詳細を見る」を押す。
2. 押された店舗の `Shop` データを `selectedShop` に保存する。
3. `shopDetailStatus` を `loading` にし、店舗IDを使って `/api/hotpepper/search?id=店舗ID` に問い合わせる。
4. 詳細情報を取得できた場合は `selectedShopDetail` に保存する。
5. 取得できない場合は `shopDetailStatus` を `error` にし、一覧で保持している `selectedShop` の情報で表示する。
6. `selectedShop` がある場合だけ、店舗詳細モーダルを表示する。
7. ユーザーはモーダル内で住所、営業時間、画像、地図、設備情報などを確認する。
8. ユーザーが別の店舗の「詳細を見る」を押した場合は、`selectedShop` と `selectedShopDetail` をその店舗の内容に差し替える。
9. 閉じるボタン、背景クリック、Escキーのいずれかで `selectedShop` と `selectedShopDetail` を `null` に戻す。

実装イメージ:

```ts
const handleSelectShop = async (shop: Shop) => {
  setSelectedShop(shop)
  setSelectedShopDetail(null)
  setShopDetailStatus('loading')

  try {
    const detail = await fetchShopDetail(shop.id)
    setSelectedShopDetail(detail)
    setShopDetailStatus('ready')
  } catch {
    setShopDetailStatus('error')
  }
}

const handleCloseShopDetail = () => {
  setSelectedShop(null)
  setSelectedShopDetail(null)
  setShopDetailStatus('idle')
}
```

## 詳細画面で表示する情報
店舗詳細モーダルでは、課題の必須項目を中心に表示する。

| 表示項目 | `Shop` の項目 | 備考 |
| --- | --- | --- |
| 店舗名称 | `name` | 見出しとして表示 |
| 住所 | `address` | 地図リンクにも使用 |
| 営業時間 | `open` | 改行がある場合もそのまま表示 |
| 定休日 | `close` | 取得できる場合に表示 |
| 画像 | `imageUrl` | 大きめに表示 |
| アクセス | `access` | 補足情報として表示 |
| ジャンル | `genre` | 店舗選びの判断材料 |
| 予算 | `budget` | 店舗選びの判断材料 |
| キャッチコピー | `catchCopy` | 店舗の特徴として表示 |
| 地図 | `address` | Google Map の埋め込み表示に使用 |
| 個室 | `privateRoom` | 取得できる場合に表示 |
| 禁煙席 | `nonSmoking` | 取得できる場合に表示 |
| カード可 | `card` | 取得できる場合に表示 |
| 駐車場 | `parking` | 取得できる場合に表示 |
| Wi-Fi | `wifi` | 取得できる場合に表示 |
| クーポンURL | `couponUrl` | 取得できる場合に表示 |
| Hot Pepper店舗URL | `hotPepperUrl` | 外部リンクとして表示 |

地図は Google Map の iframe を使って、店舗詳細モーダル内に表示する。
住所が取得できている場合は、`address` をもとに地図を表示する。
地図を入れることで、店舗情報を読んだあとに別ページへ移動しなくても、場所のイメージを確認できるようにする。

設備情報はすべてを大きく表示すると読みにくいため、詳細モーダル内では「個室」「禁煙」「カード」「駐車場」「Wi-Fi」など、来店判断に使いやすい項目を小さな情報チップとして表示する。
取得できない項目は無理に表示せず、空欄の見た目を出さない。

## 詳細表示のクリア条件
古い店舗詳細が残らないよう、以下の場合は `selectedShop` を `null` に戻す。

- モーダルの閉じるボタンを押したとき
- モーダル外側の背景を押したとき
- Escキーを押したとき
- 現在地を再取得したとき
- 検索半径を変更したとき
- ご当地カテゴリを切り替えたとき
- 通常検索を実行し直したとき
- 通常検索とご当地カテゴリ検索を切り替えたとき

## UI・CSS方針
既存の `.shop-actions a` と同じ見た目で、`.shop-actions button` も扱えるようにする。

変更イメージ:

```css
.primary-button,
.secondary-button,
.shop-actions a,
.shop-actions button {
  min-height: 44px;
  border-radius: 6px;
  font: inherit;
  font-weight: 700;
  text-decoration: none;
  cursor: pointer;
}
```

「詳細を見る」は内部操作だが、店舗カード下部ではリンクボタンと並ぶため、視覚的には同じ大きさにする。
スマートフォン幅では既存の `flex-wrap` により、横幅が足りない場合は自然に折り返す。

店舗詳細は以下の構成で表示する。

| 要素 | 役割 |
| --- | --- |
| `.shop-modal-backdrop` | 画面全体を覆う半透明の背景 |
| `.shop-modal` | 店舗詳細を表示する本体 |
| `.shop-modal-content` | 写真・店舗情報・地図を並べる領域 |
| `.shop-modal-map` | Google Map iframe を表示する領域 |
| `.shop-modal-close` | モーダルを閉じるボタン |

モーダルはPCでは画面中央に表示し、スマートフォンでは画面幅に合わせて余白を小さくする。
内容が長い場合はモーダル内をスクロールできるようにする。
PCでは左側に写真と店舗情報、右側に地図を置く。
スマートフォンでは1カラムにして、写真、店舗情報、地図の順に縦に並べる。

CSSイメージ:

```css
.shop-modal-backdrop {
  position: fixed;
  inset: 0;
  display: grid;
  place-items: center;
  padding: 24px;
  background: rgba(31, 21, 12, 0.48);
  z-index: 20;
}

.shop-modal {
  width: min(720px, 100%);
  max-height: min(760px, calc(100vh - 48px));
  overflow: auto;
  border-radius: 8px;
  background: #fffdf8;
}

.shop-modal-content {
  display: grid;
  grid-template-columns: minmax(0, 1fr) 320px;
  gap: 20px;
}

.shop-modal-map iframe {
  width: 100%;
  min-height: 280px;
  border: 0;
  border-radius: 8px;
}
```

## アクセシビリティ
- 「詳細を見る」は `button type="button"` にする。
- 店舗詳細モーダルには `role="dialog"` と `aria-modal="true"` を指定する。
- モーダルには店舗名を見出しとして置き、`aria-labelledby` で紐づける。
- 閉じるボタンには「閉じる」と分かる `aria-label` を付ける。
- Escキーで閉じられるようにする。
- モーダル表示中は背景側の操作を避ける。
- 「ホットペッパーで見る」と「地図で開く」は外部リンクのため、既存通り `target="_blank"` と `rel="noreferrer"` を指定する。

## 失敗時・例外時の扱い
- `selectedShop` が `null` の場合は店舗詳細モーダルを表示しない。
- 画像URLが空の場合は、店舗カードと同じく画像なしの表示にする。
- 住所が空の場合は、地図リンクを表示しない、またはリンクを無効化する。
- 住所が空の場合は、Google Map iframe も表示しない。
- Hot Pepper店舗URLが空の場合は、「ホットペッパーで見る」を表示しない。
- 詳細取得に失敗した場合は、一覧で保持している店舗情報だけでモーダルを表示する。
- モーダル表示中に再検索された場合は、古い店舗情報を残さずモーダルを閉じる。
