# 通常検索設計
## 目的
キーワードや条件を指定して、現在地周辺の飲食店を検索できるようにする。

ご当地カテゴリ検索では見つけにくい店名、料理名、ジャンル、予算などで探したい場合に使う。

## 基本方針
ご当地カテゴリ検索と同じ Hot Pepper API プロキシを使う。
フロントエンドから Hot Pepper API を直接呼ばず、`/api/hotpepper/search` に検索条件を渡す。

通常検索でも、検索地点は現在地の緯度・経度を使う。
そのため、現在地が未取得の場合は先に現在地取得を案内する。

## 画面
検索条件入力画面に「通常検索に切り替える」ボタンを置く。
押した場合は、通常検索用の入力欄を表示する。

通常検索で入力できる条件:

| 項目 | 内容 |
| --- | --- |
| キーワード | 店名、料理名、食べたいものなど |
| 検索半径 | 300m / 500m / 1km / 2km / 3km |
| ジャンル | 必要に応じて指定 |
| 予算 | 必要に応じて指定 |
| 個室あり | チェックした場合だけ指定 |
| 禁煙席あり | チェックした場合だけ指定 |
| 英語メニューあり | チェックした場合だけ指定 |
| カード可 | チェックした場合だけ指定 |
| ランチあり | チェックした場合だけ指定 |

## 処理フロー
1. ユーザーが「通常検索に切り替える」を押す。
2. 通常検索用の入力欄を表示する。
3. ユーザーが検索条件を入力して「検索する」を押す。
4. 現在地の緯度・経度がなければ、現在地取得を案内する。
5. 現在地があれば `/api/hotpepper/search` に検索条件を送る。
6. サーバー側で `HOTPEPPER_API_KEY` を付けて Hot Pepper API に問い合わせる。
7. 取得した店舗を一覧表示する。
8. 「もっと表示」を押した場合は、次の検索結果を追加で取得する。

## APIプロキシへ送る検索条件
通常検索では、以下の条件を `/api/hotpepper/search` に渡す。

| パラメータ | 内容 |
| --- | --- |
| `lat` | 現在地の緯度 |
| `lng` | 現在地の経度 |
| `range` | 検索半径。`1` から `5` |
| `keyword` | 検索キーワード |
| `genre` | ジャンル |
| `budget` | 予算 |
| `start` | 検索開始位置。Hot Pepper API は `1` 始まり |
| `count` | 取得件数 |
| `order` | 並び順。初期値は `4` |

チェックボックスの条件は、チェックされている場合だけ送る。

| フロント側 | Hot Pepper API側 |
| --- | --- |
| `privateRoom` | `private_room` |
| `nonSmoking` | `non_smoking` |
| `english` | `english` |
| `card` | `card` |
| `lunch` | `lunch` |

## 表示する店舗情報
通常検索結果では、ご当地カテゴリ詳細と同じ店舗カードを使う。

表示する内容:
- 店舗名
- サムネイル画像
- ジャンル
- 予算
- アクセス
- キャッチコピー
- 営業時間
- Hot Pepper公式ページへのリンク
- 地図で開くリンク

## 表示件数
1回の検索で7件取得する。

「もっと表示」を押した場合は、取得済み件数に `1` を足した値を次の `start` にする。

例:
- すでに7件取得済みの場合: `start=8`
- すでに14件取得済みの場合: `start=15`

## 失敗時の扱い
- 現在地が未取得の場合: 現在地取得を案内する。
- 検索結果が0件の場合: 検索半径を広げる、または条件を減らす案内を表示する。
- 通信に失敗した場合: 店舗情報を取得できなかった旨を表示する。
- `HOTPEPPER_API_KEY` が未設定の場合: エラーメッセージを表示する。
- 画像が取得できない場合: 画像なしでも店舗情報を表示する。
